# Reading Path — Service Management

Which of the 345 Service Management KB articles to read, and in what order. Selection criterion: **an article earns Tier 1 only if it changes how you design or troubleshoot configuration**. Setup, email/OAuth, SAML/LDAP, installation, logs, version notes, AI Hub feature descriptions and legacy "versión anterior" articles are excluded.

## Tier 3 — Operational, summarized separately

Installation and upgrades, email/SMTP/OAuth mailbox setup, SAML/LDAP/SCIM providers, logs and performance, release notes, AI Hub feature catalog, Virtual Service Agent channels (Teams, WhatsApp, Slack), gamification and version migrations are captured as durable behavior in [operations.md](operations.md), not as design guidance. Read the original article only when the task is exactly that procedure.
